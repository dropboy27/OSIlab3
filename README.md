# Лабораторная работа №3

Метод Монте-Карло: оценка вероятности того, что две верхние карты колоды имеют одинаковое достоинство.

## Сборка

```bash
mkdir build
cd build
cmake ..
make
```

## Запуск

из билд

```bash
./main 1000000 4
```

`1000000` — количество экспериментов, `4` — количество рабочих потоков.

С указанием `seed`:

```bash
./main 1000000 4 42
```

## Пересборка после изменения кода

Из билд:

```bash
make
```

## Полная пересборка

Из билд:

```bash
cd ..
rm -rf build
mkdir build
cd build
cmake ..
make
```

## strace 

Из билд:

```bash
strace -f -e clone,clone3 ./main 1000000 4
```


```bash
strace -f ./main 1000000 4
```

## top  посмотреть работающие потоки

Из билд:

```bash
./main 100000000 4 &
top -H -p $!
```


посмотреть список потоков:

```bash
./main 100000000 4 &
ps -T -p $!
```
